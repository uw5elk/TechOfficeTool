# Word & Images Tool (UW5ELK)

Програма для Windows з графічним інтерфейсом для роботи з документами Word та зображеннями.

## Можливості
1. **Стиснення зображень у Word (.docx)** — зменшує розмір файлів, стискаючи картинки.
2. **Конвертація .doc → .docx** — пакетна конвертація старих документів (потрібен Microsoft Word).
3. **Стиснення звичайних зображень** — пакетна обробка JPG, PNG, TIFF, WEBP тощо.
4. **Пакетне перейменування фото** — за шаблоном, з підтримкою EXIF-дат та dry-run.
5. **Пакетне видалення EXIF** — очищення метаданих (з опцією збереження ICC-профілю та бекапів).
